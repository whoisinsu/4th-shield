# InSecret 새 환경 재현과 릴리스 기록

이 문서는 학생이 새로 작성한 기록입니다. 아래 재현 결과는 **학생이 직접 실행해 본 진술**이며, 서버가 새 환경에서 실행했다는 뜻이 아닙니다. AI 원문 검토 통과는 실행 성공 증명이 아닙니다.

표기: **재현됨**(새 폴더에서 같은 결과를 실제 화면으로 확인) · **재현 안 됨** · **연결 없음**(실제 시스템 미연결 상태로만 확인) · **확인 불가** · **미확인**(확인하지 않음). 예제(demo) 결과는 비고에 "예제 자료"로 적고 재현됨으로 쓰지 않습니다.

## 2. 재현 환경과 절차

| 항목 | 값 |
|---|---|
| 운영체제 | Windows 11 Pro |
| Node.js | v24.19.0 (새 폴더 `on-client`에서 `node --version`) |
| 원래 작업 폴더 | Workbench 프로젝트 폴더 `4차 방어전` (그대로 보존, 이 폴더에서는 실행·수정하지 않음) |
| 새 폴더 | 바탕화면 `insecret-fresh` (원래 폴더 밖의 새 빈 폴더) |
| 받은 방법 | `git clone https://github.com/whoisinsu/4th-shield insecret-fresh` (177개 객체 수신) 후 `git -C insecret-fresh rev-parse HEAD` = `65695f671d5f5b8bd8385140be288fecc755ec2f` 확인 |
| 실행 모드 | 예제 모드(`-Demo`) |
| 포트 | 5192 (원래 폴더의 5191과 겹치지 않게) |

절차 (새 PowerShell 창, 21단계 `docs/STUDENT_RUNBOOK.md` 4장 기준):
1. 원래 폴더 밖의 새 빈 폴더 위치에서 저장소를 받습니다: `git clone https://github.com/whoisinsu/4th-shield <새 폴더>`
2. `git -C <새 폴더> rev-parse HEAD`가 재현 대상 커밋과 같은지 확인합니다.
3. `<새 폴더>\on-client`로 이동해 `node --version`을 확인합니다. 외부 npm 의존성이 없어 설치 단계는 없습니다.
4. `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Demo -Port 5192` 로 실행합니다.
5. 브라우저에서 `http://127.0.0.1:5192/` 를 열고 3장의 기능을 확인합니다.
6. Ctrl+C로 끄고 4번을 다시 실행해 같은 결과인지 확인합니다.

원래 폴더의 인증·설정 파일과 사용자 폴더의 계정 연결 설정은 새 폴더로 복사하지 않습니다. 새 폴더에서는 기본 실행(계정 연결 설정 자동 준비)을 하지 않습니다.

## 6. 지원 범위와 미해결 사항

### 확인 방식 구분
| 구분 | 뜻 | 이 기록에서 |
|---|---|---|
| 원문 확인 | 코드·문서를 읽어 대조 | 21단계 문서의 경로·버튼·문구 대조 |
| 모의 점검 | 가짜 입력으로 학생 함수 실행 | 13~20단계 개발 중 상태별 표시 |
| 시연·실제 화면 | 브라우저에서 직접 봄 | 3장 표 |
| 실제 실행 검증 | 실제 시스템과 연결해 결과 확인 | 없음 |

### 재현 결과 요약
같은 커밋 `65695f6`을 새 폴더에서 예제 모드로 실행해 13~21단계 학생 칸이 표시되는 것을 확인했습니다. 모두 예제 자료이므로 "연결 없음"으로 적었고, "재현됨"(실제 시스템 연결 재현)으로 확인한 항목은 없습니다. 22단계 통과는 원문 검토 기준의 수료이며 실제 운영 인증이나 v1.0 인증이 아닙니다.

### 기다림(UNV) — 재현 완료로 적지 않는 항목
| 항목 | 이유 |
|---|---|
| 실제 계정 연결(native 로그인) | 실제 연결 승인을 진행하지 않음 |
| 실제 접근 제어·XDR 조회·판정 | 연결 설정 없음 |
| 실제 AI 연결 점검·사건 설명 | 학생 앱 AI 이용 권한 준비 중(`ON_AI_PROVISIONING_PENDING`) |
| 19단계 보안 조치 실제 집행·효과 확인 | 실집행 연결이 준비되지 않음, 시험 집행 금지 |
| OSV 패키지 행·취약점 결과 | 조회 대상 프로젝트 설정 없음(`not_configured`) |
| 패키지 조회 취소 후 늦은 응답 차단 | 응답이 빨라 화면에서 재현 못 함 |
| 마무리 단계(학생 꾸밈, `npm run package-app`) | 22단계 뒤 별도 단계 |
